# 1.プロジェクトの目的と価値

<details>
<summary>要領</summary>

> プロジェクトを実施する理由、達成しようとする目標、およびプロジェクトがもたらすであろう価値（ビジネス価値、その他の便益）を記述します。
</details>

- 「大戦国」＝固有名詞であり、それ即ちイイダリョウが作る戦国時代を題材とした『作品』を意味する。元々は「ゲームを作りたい」という欲望から、ボードゲームの要件定義→基本設計→没の繰返しで今に至る。

- 「大戦国」はイイダリョウが少年時代から培ったロマンであるが、大人〜おじさんになって中々進めるための環境・リソースが整わず、進捗のない期間が長く続いた。

- そんな中、現在のイイダリョウはエンジニアの仕事に従事しており、プログラム開発が可能な領域にいる為、この境遇を是非「大戦国」へ活かしたい思いである。また、「大戦国」を経て仕事へのフィードバックができるとシナジー効果があってより良く考えている。

- 「大戦国」の可能性は広く捉えており、ゲームは勿論、シミュレーター・ビジュアライザー・データサイエンス・等、色々なモノを作りたいと考えている。

- 現在は何をするにも土台となるデータ整備を推進したく、元々その為に年表入力をスプレッドシートベースで行なっていた。しかし、データ量が膨大になりすぎてこの仕組みではスムーズにデータ入力できない状況に陥っている。

- 本プロジェクトによって年表データ入力がスムーズに行なえるシステムの構築をすることで、「大戦国・年表」の入力促進→完成→次のステップへの礎を築く。

</br>
